# На каком объёме процесс упал с MemoryError 
~~~
gao@fedora:~$ ( ulimit -v 307200; python3 ~/eat.py )
MemoryError на 60 МБ
~~~
# Что делает ulimit -v
`ulimit -v` - ограничивает память процесса до указанного вами значения, если запустить без лимита то память кончится и системе будет плохо пока OOM Killer не вступит в бой

# Как ядро выбирает жертву, когда память кончается у всей системы
По oom_score: больше всех памяти, не критичный для системы

# Что такое oom_score (out of memory score) 
`oom_score` - числовой показатель от 0 до 1000, который ядро линукса присваивает каждому запущенному процессу
